## 工具安装

### Go

编译与运行本项目需要 Go 工具链（go.mod 要求 Go 1.25+，本机已装 go1.25.5）。请按[官方安装文档](https://golang.org/doc/install)安装并配置好 `GOPROXY`（国内建议 `https://goproxy.cn,direct`）。

### Docker

中间件（MongoDB / Redis / etcd / Kafka / MinIO）通过 Docker 运行，开发机需安装 [Docker](https://docs.docker.com/get-docker/)。

## 依赖管理

本项目使用 [go modules](https://github.com/golang/go/wiki/Modules) 管理依赖，无需额外工具。

> 说明：上游 OpenIM 文档中的 Vagrant 虚拟机、`make init` 等流程在本项目已不再使用（本项目用 Mage 构建：`mage build` / `mage start`）。
