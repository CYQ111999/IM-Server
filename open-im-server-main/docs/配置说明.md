# 配置说明

## 设计思路

随着软件工程复杂度提升，配置管理越来越重要。YAML 等配置文件为系统提供必要参数，但也给开发者带来额外管理开销。本项目的配置体系遵循以下原则：

1. **集中管理**：所有服务的配置集中在 `config/` 目录，每个服务一份 YAML，公共配置放 `share.yml`。
2. **默认值兜底**：配置结构体中的字段大多带默认值，缺失时可自动兜底，保证配置完整一致。
3. **环境变量覆盖**：支持通过环境变量覆盖配置项（见 `pkg/common/config/env.go` 中的 `EnvPrefixMap`），方便不同环境（本地/演示）切换而无需改文件。

## 配置文件清单

| 文件 | 用途 |
| --- | --- |
| `share.yml` | 全局共享配置：管理员账号、secret、消息队列引擎（kafka/redis/memory）、多端登录策略 |
| `discovery.yml` | 服务发现：etcd 地址与各 RPC 服务名（standalone 模式下自动切换为内存注册） |
| `mongodb.yml` / `redis.yml` / `kafka.yml` | 三大中间件连接配置 |
| `log.yml` | 日志配置（级别、输出、轮转） |
| `local-cache.yml` | 本地缓存分片与过期策略（auth/user/group/friend/conversation 五类） |
| `notification.yml` | 系统通知消息模板（加好友、入群、退群等 tip 消息的文案与开关） |
| `webhooks.yml` | 消息回调 webhook 配置 |
| `openim-api.yml` / `openim-msggateway.yml` / `openim-msgtransfer.yml` / `openim-push.yml` | 各服务自身配置 |
| `openim-rpc-*.yml` | 各 RPC 服务自身配置 |

## 本地运行时的关键配置

所有配置默认指向 `localhost` 对应端口，即"中间件在 Docker、Go 服务在宿主机"的混合模式：

- MongoDB：`localhost:37017`
- Redis：`localhost:16379`
- etcd：`localhost:12379`
- Kafka：`localhost:19094`

> 上游文档中的 `scripts/init_config.sh` 自动生成模板流程在本项目已移除，直接编辑 `config/` 下的 YAML 即可。

## 环境变量覆盖

配置加载由 `pkg/common/config/load_config.go` 完成，使用 viper 并开启 `AutomaticEnv()`，因此**任意配置项都可以用环境变量覆盖**，无需改文件。

### 命名规则

环境变量名 = 文件前缀 + `_` + 配置项路径（大写，`.` 替换为 `_`）。

文件前缀由 `pkg/common/config/env.go` 的 `EnvPrefixMap` 生成，规则是：

```
IMENV_ + 去掉扩展名的文件名的全大写，并将 "-" 替换为 "_"
```

例如：

| 配置文件 | 环境变量前缀 |
| --- | --- |
| `share.yml` | `IMENV_SHARE` |
| `redis.yml` | `IMENV_REDIS` |
| `mongodb.yml` | `IMENV_MONGODB` |
| `openim-api.yml` | `IMENV_OPENIM_API` |
| `openim-rpc-user.yml` | `IMENV_OPENIM_RPC_USER` |

### 使用示例

```bash
# 覆盖 openim-rpc-user.yml 中的 rpcPort（同名配置项）
export IMENV_OPENIM_RPC_USER_RPC_PORTS="10110,10111,10112"

# 覆盖 redis.yml 中的地址
export IMENV_REDIS_ADDRESS="127.0.0.1:6379"
```

说明：

- 切片类型的配置项用**逗号分隔**（加载器注册了 `StringToSliceHookFunc(",")`）。
- 时间间隔类型（如超时）会按 Go 的 duration 语法解析，例如 `30s`、`1m`。
- 环境变量优先级高于 YAML 文件，适合容器部署或多环境下临时调整参数。本项目本地运行时不依赖任何环境变量，全部取 YAML 中的默认值。

### 配置加载签名

```go
// configDirectory, configFileName, envPrefix, 目标配置结构体
err := config.Load("./config/", "redis.yml", "IMENV_REDIS", &redisConf)
```

Kubernetes 环境下会改为从 `MOUNT_CONFIG_FILE_PATH` 指定的挂载目录读取同名文件。
